# ⚔️ RTS Battle Simulator (Version 1)

> *"If you can't have it, you build it."*

An interactive, browser-based **HTML5 Canvas Battle Simulator** built to explore swarm intelligence, flocking physics, and real-time combat state machines.

---

## 🌟 Features (V1 MVP)

- 🦅 **Boids Flocking Physics:** Armies move organically across the battlefield using the three core principles of flocking: *Separation*, *Alignment*, and *Cohesion*.
- 🛡️ **Dynamic Formations & Slot Filling:** Surviving units dynamically adjust their positions to fill empty spots when front-line soldiers fall, maintaining tight battle ranks without gaps.
- ⚡ **Symmetric Combat Engine:** Randomized execution order and simultaneous damage application ensure fair, balanced 1-on-1 and legion-level combat.
- ⏱️ **Battle Control System:** Built-in Start and Pause/Stop buttons allow real-time inspection of unit formations and battle progress without resetting the state.
- 🎯 **CPU AI General:** Automated enemy legion targeting, state transitions (`MARCH` vs. `COMBAT`), and tactical positioning.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5 Canvas, JavaScript (ES6+), CSS3
- **Algorithms:** Boids Flocking Algorithm, Finite State Machines (FSM), Dynamic Grid Offset Calculation
- **AI Co-Developers (via Google Antigravity IDE):**
  - **Gemini 3 Flash:** Rapid Canvas rendering, UI event handling, and physics loop optimization.
  - **Claude Sonnet 4.5:** State machine architecture, combat array synchronization, and logic debugging.
